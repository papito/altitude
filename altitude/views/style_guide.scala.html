Icons

Font Awesome 5, solid style (fas). These are the icons in use in the templates and scripts, each with the number of places it appears; reuse one before adding another.

Buttons

Success, warning and error buttons signal an outcome, not emphasis. Hover and keyboard focus share one look, through :focus-visible and not :focus, so a button a dialog returns focus to is not left glowing after a mouse click.

Forms

A field in error takes the error class, with the message in a div.error above it inside the form. Mark a field that cannot be edited with readonly.

Menus & dialogs

Both controls are live. A row's actions sit in a ⋯ context menu, which stays a list of actions; each action, like an Add button, opens a separate modal anchored below its control. Submit the dialog blank to see the validation state, or with a name to see a completed operation.

@* js/style-guide.js builds both controls here, with the functions the explorer lists build theirs with *@

Feedback

The outcome of an action is reported in the snackbar: success for a completed one, warning for one that partly applied, error for a failure. A failure to load a page area is a server error message in place.

#serverError: something went wrong on the server.
Loading indicator: fa-spinner fa-spin
