@(paths: String, crushed: String, blown: String, shows: String = "", id: String = "", disabled: String = "") @* The Histogram, the one markup of it. It is a button, the Clipping blink's switch, so the Alpine component it is rendered under gives `clippingBlink` and `toggleClippingBlink()`. The parameters are Alpine expressions of that component: `paths` the paths by channel (js/common/histogram.js `channelPaths`, or `NO_PATHS`), drawn in its `HISTOGRAM_BOX`; `crushed` and `blown` the labels of the top left and right corners, an empty one showing nothing. *@
